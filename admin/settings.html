API URL in use:

Open Google Sheet

For the public website to work for everyone, the URL must be pasted in website/js/config.js and pushed to GitHub.

Auto-import leads from other Google Sheets → Clients

New rows in your lead sheet(s) (e.g. Facebook / Meta lead form sheet) are added to Clients automatically every 5 minutes. The lead sheet is only read, never changed. Same mobile number = no duplicate client (a "repeat enquiry" note is added instead).

Merge latest tabs into this Google Sheet (safe)

Keeps one Google Sheet. Adds the latest new tabs and any missing columns at the end. Your existing tabs, rows and column order are never changed; a tab with an older layout is skipped and reported. A backup copy is saved in your Google Drive first. Run again after any future update — it only adds what is still missing.

Attach Google Sheet to this project

Makes the website, admin panel and Partner Portal read and write the Google Sheet you paste here. Nothing is deleted or copied — missing tabs / columns are added, your data stays.

The Google account that deployed the Apps Script must have Editor access to that sheet.

Website Data Check — "my sheet data is not showing"

Reads Properties, Land and Projects exactly like the website does and tells you, ad by ad, what is visible and why the others are hidden (waiting approval, expired after 45 / 60 days, wrong header row, wrong column names).

New Google Sheet Database (automatic)

Creates a brand-new, empty Google Sheet in your Google Drive with every tab, column, role, listing rule and the admin / admin123 login — and switches the website, admin panel and Partner Portal to it.

⚠️ The new sheet starts empty (old data is not copied; the old sheet is not deleted and can be re-activated from Apps Script with useExistingDatabase). You will be logged out and must login again as admin / admin123.

Sheet Setup / Repair

Creates any missing tabs (PROPERTIES, NEW_PROJECTS, PROPERTY_BOOKINGS, WEBSITE_INQUIRIES, MEDIA_LIBRARY …) and adds any missing columns. Existing data is never deleted. Safe to run any time.
